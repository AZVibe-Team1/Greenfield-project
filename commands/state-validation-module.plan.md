# Create Job Seeker MongoDB Model with Beanie

## Implementation Steps

1. **Install Beanie and Motor dependencies**

- Add `beanie` (async MongoDB ODM)
- Add `motor` (async MongoDB driver)
- Add `pymongo` (MongoDB driver core)

2. **Create Address class in validators.py**

- Define reusable `Address` Pydantic model
- Include: street (str), city (str), state (StateAbbr), zip_code (ZipCode)
- Export Address class for use in schemas

3. **Create Information sub-document class**

- Fields: first_name (str, required), last_name (str, required)
- Include: email (Email), phone (USPhoneNumber)
- Include: address (Address, required)

4. **Create Application sub-document class**

- Fields: job_id (str, foreign key), employer_id (str, foreign key)
- Include: date_applied (datetime), application_status (Literal enum)
- Status options: "Submitted", "Interviewed", "Offered", "Rejected"

5. **Create Seeker Beanie Document model**

- File: `backend/schemas/seeker.py`
- Inherits from Beanie's `Document` class
- Include all required fields per specification
- Configure MongoDB collection name

## Key Details

### Seeker Model Fields:

- `_id`: PydanticObjectId (auto-generated by Beanie)
- `information`: Information (sub-document, required)
- `password_hash`: str (min_length=6, required)
- `created_at`: datetime (default_factory=datetime.now)
- `resume`: Optional[str] (sub-document string)
- `pay_range`: List[int] with exactly 2 elements [low, high]
- `pay_unit`: Literal["Hourly", "Monthly", "Yearly"]
- `education_level`: Literal["BA", "BS", "MA", "MS", "MBA", "PhD"] (required)
- `edu_focus`: str (required)
- `key_skills`: List[str] (max 15 elements)
- `applications`: List[Application] (list of sub-documents)

### Validation Rules:

- Use Pydantic Field for constraints (min_length, max_items, etc.)
- Use Literal types for enums
- Use datetime for timestamps
- Ensure all required fields are marked properly
